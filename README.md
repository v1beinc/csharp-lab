# C# Lab — тест по C#

Готовый адаптивный учебный тренажёр на русском языке. Работает на телефоне, планшете и компьютере. Статический сайт без обязательных зависимостей, платных API и серверной базы.

**Сайт на GitHub Pages:** https://v1beinc.github.io/csharp-lab/

## Источник данных — текущая версия

Общая Google Таблица **подключена**: все посетители получают вопросы из [опубликованного CSV](https://docs.google.com/spreadsheets/d/e/2PACX-1vRRA_L-nWDnRgfb0YPEGuhKkFHq2Ng2guiRxZcTK7APsPlTgOOU0vjT-npXkG_z0gFyDvGImOLJnvlp/pub?gid=64005552&single=true&output=csv). На момент подключения проверены 48 вопросов по шести темам. URL хранится в `dist/config.js`. При открытии сайта запускается загрузка из Google; ручной ввод ссылки не требуется.

- Без Google Таблицы сайт явно показывает деморежим: 48 вопросов из `questions.js`.
- После подключения CSV-ссылки вопросы автоматически загружаются из Google при открытии сайта. Форма также позволяет обновить их вручную.
- Для общей таблицы на всех устройствах задайте `googleSheetUrl` в `dist/config.js`. Затем выполните `npm run build:pages`, закоммитьте изменения и отправьте их на GitHub.
- При сбое Google используется последняя корректная копия того же источника с предупреждением. Если её нет, тестирование блокируется, чтобы не выдавать демовопросы за данные Google.
- Результаты хранятся только в `localStorage` браузера. Запись результатов в Google не реализована.

## Запуск

Нужны Git и Node.js 20 или новее (рекомендуется актуальная LTS). Python и npm install не нужны.

```bash
git clone https://github.com/v1beinc/csharp-lab.git
cd csharp-lab
npm start
# Открыть http://127.0.0.1:3000
npm test
```

Остановка: Ctrl+C. Следующий запуск: `cd csharp-lab`, затем `npm start`. Обновление исходников: `git pull --ff-only`.

Если Node.js недоступен, но установлен Python: Windows — `py -m http.server 3000 --bind 127.0.0.1 --directory dist`; Linux/macOS — `python3 -m http.server 3000 --bind 127.0.0.1 --directory dist`. Не открывайте index.html через file://: браузер блокирует импорты ES-модулей.

## Что реализовано

- 48 вопросов: основы, управление потоком, ООП, коллекции/LINQ, исключения, асинхронность.
- Тренировка с мгновенным объяснением, адаптивная тренировка и экзамен на 15 минут.
- В адаптивном режиме начало с уровня 1; верно → сложность +1, неверно → −1, границы 1–3. Если нужный уровень закончился, выбирается ближайший. Это простая учебная эвристика, не психометрическая модель IRT.
- Выбор темы, имени и числа вопросов; без повторов внутри попытки.
- Результат, оценка 2–5, разбор кода и ошибок, экспорт отчёта TXT.
- История последних 100 попыток и статистика в localStorage; экспорт истории JSON.
- Google Таблицы CSV, проверка данных, импорт CSV-файла и возврат к встроенной базе.
- Адаптивная вёрстка, клавиатурное управление, видимый фокус, подписи элементов.

## Google Таблицы

1. Импортируйте `docs/questions-template.csv` в новую таблицу.
2. Редактируйте вопросы, сохраняя первую строку с именами столбцов.
3. Файл → Поделиться → Опубликовать в интернете → нужный лист → CSV.
4. В приложении откройте «Источник вопросов», вставьте ссылку и нажмите «Загрузить вопросы».
5. Подключённая таблица обновляется при каждом открытии сайта; также есть ручная кнопка обновления. Google может публиковать изменения с задержкой.

Если браузер блокирует загрузку из-за CORS или доступа Google, скачайте лист как CSV и используйте «Импорт CSV-файла». Настройка источника и вопросы сохраняются только в текущем браузере; у других посетителей изначально встроенная база. Чтобы установить общий источник для всей группы, задайте URL в `dist/config.js` и обновите GitHub Pages.

Поля: `id, topic, difficulty, question, a, b, c, d, correct, explanation, code`.

Темы: `basics`, `flow`, `oop`, `collections`, `errors`, `async`. `difficulty`: 1–3. `correct`: номер варианта 1–4. `code` необязательное. ID уникальны. CSV разделён запятыми, многострочные поля заключены в двойные кавычки. Лимиты: 2000 вопросов, 4 МБ. Шаблон содержит все 48 вопросов.

## Архитектура и файлы

- `dist/index.html` — оболочка и форма запуска.
- `dist/styles.css` — дизайн и адаптивная вёрстка.
- `dist/app.js` — экраны, сессия, таймер, импорт и история.
- `dist/engine.js` — независимая логика: CSV, валидация, выбор вопросов, сложность и оценки.
- `dist/questions.js` — стартовый банк заданий.
- `tests/engine.test.js` — тесты данных, CSV, адаптивности и URL.
- `docs/ARCHITECTURE.md` — обоснование архитектуры и серверный вариант.
- `docs/DEFENSE.md` — сценарий демонстрации для защиты.

## Хостинг и передача

На любом статическом хостинге публикуйте содержимое `dist`. Сборка не нужна. Например, Netlify Drop принимает папку dist; GitHub Pages также подходит. Служебные файлы Sites-хостинга исключены из этого репозитория. В исходниках нет API-ключей и паролей. Запуск не требует аккаунта автора.

Sites по умолчанию ограничивает доступ владельцем. Для показа преподавателю потребуется включить доступ через настройки сайта либо развернуть dist на публичном хостинге. Домен и тарифы стороннего хостинга управляются отдельно.

## Ограничения и проверка

Это тренажёр: ответы находятся в JS/CSV и доступны посетителю. Оценки и имя не проверяются сервером, историю можно изменить. Общей ведомости, авторизации, синхронизации между устройствами и отправки результатов в Google нет. Обновление страницы теряет незавершённую попытку; браузер запрашивает подтверждение ухода, где это поддерживается. При раннем завершении или тайм-ауте неотвеченные вопросы считаются неверными. Выбранный, но ещё не подтверждённый ответ при завершении учитывается.

Автоматические проверки: `npm test` и `node --check dist/app.js`. Тесты загрузки используют подставной CSV-ответ Google; реальную таблицу владельца нужно создать и подключить отдельно. Веб-шрифты Google Fonts необязательны: есть системные запасные шрифты. Без сети доступ к Google Таблицам и веб-шрифтам недоступен.

## GitHub на общем компьютере

Репозиторий публичный: клонирование и скачивание ZIP не требуют входа в GitHub. Для отправки изменений потребуется авторизация через браузер по запросу Git Credential Manager. Не вставляйте пароль или токен в URL и команды. На общем ПК не сохраняйте вход в аккаунт; после работы выйдите из GitHub и удалите свою запись GitHub из «Диспетчер учётных данных Windows → Учётные данные Windows», если менеджер сохранил её. В локальной папке остаются исходники, в браузере — история попыток.

Без Git можно скачать Code → Download ZIP на GitHub, распаковать и выполнить npm start в папке с package.json.

## Обновление GitHub Pages

Настройка: Settings → Pages → Deploy from a branch → main → /docs.
Исходники интерфейса редактируются в dist, затем публикационная копия обновляется:

```bash
npm test
npm run build:pages
git add dist docs scripts package.json tests README.md
git commit -m "Update site"
git push
```

Папка docs содержит статическую копию сайта, шаблон таблицы и документацию. Не правьте сгенерированные HTML/JS/CSS в docs отдельно от dist.
