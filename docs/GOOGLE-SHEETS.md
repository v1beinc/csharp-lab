# Подключение настоящей Google Таблицы

1. Откройте https://sheets.new в своём Google-аккаунте.
2. Назовите таблицу «C# Lab — вопросы».
3. Скачайте https://v1beinc.github.io/csharp-lab/questions-template.csv или файл docs/questions-template.csv из репозитория.
4. Файл → Импорт → Загрузить → выберите CSV → замените текущий лист. Разделитель — запятая. Импортируйте значения как текст, отключив преобразование текста в числа, даты и формулы, если Google предлагает этот переключатель.
5. Файл → Поделиться → Опубликовать в интернете → выберите импортированный лист → CSV → Опубликовать.
6. Скопируйте полученную CSV-ссылку (обычно https://docs.google.com/spreadsheets/d/e/…/pub?output=csv).
7. Для проверки вставьте её в «Источник вопросов» на сайте. Заголовок должен смениться с «Демо» на «Вопросы из Google Таблицы». Нажмите «Открыть CSV-источник Google», чтобы показать фактический ответ сервиса.
8. Чтобы таблица работала у преподавателя без настройки браузера, вставьте эту же ссылку в dist/config.js → googleSheetUrl, выполните npm run build:pages и отправьте изменения на GitHub.

Меняйте вопрос в Google Таблице, дождитесь публикации изменений и перезагрузите сайт. Обновлённый текст должен появиться в тесте. Это демонстрирует, что источник — Google, а не файл с вопросами. В вопросе можно временно добавить заметную метку, чтобы легче проверить загрузку.

## Что сказать на защите

После подключения общей таблицы: «Сайт размещён на GitHub Pages. Вопросы, варианты и правильные ответы хранятся в Google Таблице. При открытии браузер получает опубликованный CSV по HTTPS, проверяет структуру и загружает вопросы в движок тестирования. Копия вопросов и история результатов сохраняются в localStorage браузера. Результаты в Google не отправляются».

Пока таблица не подключена, корректный ответ другой: «Сайт в деморежиме и использует вопросы из questions.js; интеграция Google готова, но ещё не настроена».

Google Таблица с опубликованными вопросами публична. Не размещайте в ней персональные данные. GitHub Pages — статический хостинг, там нет базы данных и серверной проверки ответов.
