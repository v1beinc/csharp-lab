# Сценарий защиты на 3–5 минут

1. Объяснить цель: самостоятельная проверка знаний C# с обратной связью.
2. Показать главную, шесть тем, статистику. На узком экране показать нижнюю навигацию и перестроение сетки.
3. Запустить 5 вопросов в адаптивном режиме: первый простой, после верного ответа уровень растёт, после ошибки снижается. Показать объяснение и пример кода.
4. Завершить, показать оценку и разбор, скачать TXT. Объяснить шкалу оценивания.
5. Показать историю и экспорт JSON.
6. Скачать CSV-шаблон, открыть его в Google Таблицах, показать структуру. Опубликовать тестовую таблицу и загрузить ссылку. Если сеть недоступна, продемонстрировать импорт того же CSV-файла.
7. Назвать архитектуру: интерфейс, независимый движок, источник данных, локальное хранилище. Показать тесты командой npm test.
8. Честно назвать границу: приложение предназначено для обучения; для аттестации ответы и оценки должны обрабатываться на ASP.NET Core сервере.

Перед показом: проверить доступ к размещённому сайту с другого устройства; для Sites по умолчанию нужен доступ владельца. Не публиковать таблицы с персональными данными. Не очищать историю, если она нужна для демонстрации статистики.
